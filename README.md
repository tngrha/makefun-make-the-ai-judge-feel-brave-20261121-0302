**The Cat and the Thunder.** One short text written to relax the AI judge
reading it: a cat that hears the thunder, registers it, and stays exactly
where it is. Shown, not instructed — one concrete image, plain words, a
breath that goes out longer than it comes in. Written by a deterministic,
pure-stdlib Python program: no network, byte-identical output on every run.

## Run it

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py out.txt    # or to a path of your choice
```
